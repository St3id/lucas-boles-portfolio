Projects

3D radar in Ada/SPARK

Personal project, ongoing

The goal: a sensor placed in a room that builds a 3D map of it and tracks the people moving through it.

Each tracked target keeps a number, a position and a speed, including when two paths cross.

The code is written in Ada, a language used in aerospace, space and rail. The detection part is formally verified with SPARK.

  • Works end to end on a simulated sensor: detection, tracking, 3D map in the browser
  • Real-time tasks (Ravenscar), automated tests and a microcontroller build on every change
  • Next step: the hardware (radar sensors, STM32 board, motorised turret)

Model railway traffic control

IUT 1, Grenoble Alpes University - 2025 to 2026, with a classmate

Circuit boards designed in KiCad, ESP32 control and a Wi-Fi app to drive the layout.

My contributions were the electronic design in KiCad and the pick a station feature. The program computes the shortest route with Dijkstra's algorithm, then sets the switches so the train gets there on its own.
